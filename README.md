# Student Grade Calculator

A simple Java mini project that calculates a student's total marks, average, and grade based on three subject marks.

This project was created as part of my learning journey in **BSc in Information Technology**, to practice basic Java programming concepts such as user input, variables, arithmetic operations, and conditional statements.

## Technologies Used

* Java
* Visual Studio Code

## What I Practiced

* `Scanner` for user input
* Variables and data types
* Arithmetic calculations
* `if-else` statements
* Basic Java programming
